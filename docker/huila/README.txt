Docker task: support-bundle

Что делает проект

В рамках этой задачи был создан отдельный Docker-образ в папке `docker/huila`.  
Образ собирается на базе Ubuntu 22.04. 
Внутри него создаётся рабочая папка /opt/support-app, куда добавляются шаблон конфигурации, README и файл логов. 
Отдельно указаны папки /data и /opt/support-app/logs для хранения данных и логов в volume. 
Контейнер не выполняет приложение, а просто остаётся запущенным за счёт sleep infinity.

После сборки образ был:
- собран локально;
- перетегирован для Docker Hub;
- запушен в Docker Hub;
- использован для запуска контейнера уже из образа из registry.

Внутри контейнера были выполнены действия, которые требовались по заданию:
- Создан файл /data/config.env на основе шаблона /opt/support-app/config.template.
- Создан файл /data/report.txt.
- В /data/report.txt вручную записан вывод требуемых команд:cat /etc/os-release, pwd, whoami, ls -la, cat, date.
- Создан файл /data/manual-note.txt.
- В /data/manual-note.txt написано, что хранится в /opt/support-app, а что хранится в /data.
- Все созданные файлы сохранены в /data.
- /data подключена как внешний volume, поэтому файлы должны сохраниться после удаления и пересоздания контейнера с тем же volume.

Состав проекта

- `Dockerfile` — инструкция по сборке Docker-образа;
- `README.md` — описание выполненной задачи, команд и результатов.
- config.template - шаблон конфига
- app.log - логи
